# GATE 2025 CS1 Dataset

- **Paper**: Computer Science & Information Technology (CS1)
- **Year**: 2025
- **Organizer**: IIT Roorkee
- **Questions**: 65 (GA 1–10, CS 11–65)
- **Marks**: 100

## Files
- `questions.json` — frontend-safe (formatted text, options, and figure references)
- `answers.json` — server-side only (keys + marking)
- `assets/` — clean figure crops for Q5, Q7, Q9, Q21, Q27, Q40, Q50, Q53, Q55, Q57, Q60, Q62, and Q64

Question text uses paragraph breaks rather than source-PDF line wrapping. Q9's four
answer patterns are selectable image options; the other figures are referenced
through each question's `assets` array.
