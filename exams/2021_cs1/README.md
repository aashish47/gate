# GATE 2021 CS1 Dataset

- **Paper**: Computer Science & Information Technology (CS1 / Set 1)
- **Year**: 2021
- **Organizer**: IIT Bombay
- **Session**: 5
- **Questions**: 65 | **Marks**: 100

## Files
- `questions.json` — frontend-safe questions, options, tables, and figure references
- `answers.json` — official answer key and marking
- `assets/` — source-cropped question figures and image-based options

Question IDs are unique across the full paper: GA questions are 1–10 and CS
questions are 11–65. `source_question_number` retains each section's printed
question number, and `source_page` is the 1-based page number in the supplied PDF.

## Formatting
- Mathematical notation uses LaTeX delimiters.
- Tabular data uses structured `headers` and `rows`.
- Code and SQL use fenced code blocks.
- Figure and image-option assets are cropped from the source question scan.
